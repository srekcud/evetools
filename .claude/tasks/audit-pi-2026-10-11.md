## P1

### 1. La valeur journalière PI compte plusieurs fois la même matière d'un tier à l'autre — `bug`, `pi`
- Constat : `totalDailyIsk` additionne la valeur de chaque type produit, P0 extraits compris, sans retirer ce que les usines consomment.
- Preuve : `src/Service/Planetary/PlanetaryProductionCalculator.php:95-100` ; `$consumptionByType` (`:199`) ne sert qu'au `delta` (`:120-123`) ; KPI `PlanetaryStatsProvider.php:75`, `:150` (mensuel ×30).
- Impact : une chaîne P0 → P1 → P2 affiche P0 + P1 + P2 alors que seule la sortie finale est vendable ; KPI « ISK estimé/jour » gonflé.
- Test : extracteur qui produit exactement ce que consomme une usine P1 (prix P0 = 5, P1 = 400) → attendu valeur P1 seule (ou valeur nette exposée à part) ; obtenu P0 + P1.
