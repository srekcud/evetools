# Orchestrateur de la boucle de nuit (un passage = un tick court, ≤ 12 appels d'outils)

Tu es déclenché périodiquement. Contexte : `/home/sdu/Documents/projects/perso/evetools/.claude/tasks/night-queue.md` (file, parallélisme, id de la tâche planifiée) et le journal indiqué dedans. Ne code rien, ne lis pas `src/`. Réponds en 3 lignes. Termine toujours par l'étape 7 (settle de ton thread).

1. Lis `night-queue.md`. Pour chaque issue de la file, dans l'ordre : `zsh -ic 'gh issue view N --json state --jq .state'`. `CLOSED` = faite.
2. `t3_thread_list` (statuses toutes, titleContains `] #`, ce qui couvre `[nuit] #` et `[fix] #`, projet courant) : associe chaque issue à son thread le plus récent. Pour chaque issue, cherche une PR ouverte : `zsh -ic 'gh pr list --state open --search "head:fix/night-N" --json number,url,headRefName'` (une tête `fix/night-N` ou `fix/night-N-*`). **Une issue dont le thread a ouvert une PR est terminée pour la boucle**, quel que soit le statut du thread (décision de Sylvain du 2026-11-06).
3. Limite d'usage : pour tout thread `failed` ou `interrupted`, lis son dernier message (`t3_thread_read`, limit 2, maxCharsPerItem 600). S'il annonce une limite avec une heure de reset : si l'heure actuelle (`date +%H:%M`, fuseau Europe/Brussels) est AVANT reset+2 min, **ne lance rien ce tick** (le quota est partagé) et termine ; sinon reprends-le avec `t3_thread_send` (« Reprise après la limite d'usage : relis le journal et ton worktree, continue. »), une seule reprise par tick.
4. Issue avec PR ouverte (étape 2) : note `[orchestrateur] #N PR à relire (<url>)` dans le journal (une fois), ne la relance jamais, et son thread ne compte plus dans le parallélisme. Threads `completed` dont l'issue est encore ouverte et sans PR : si le journal contient un Blocage `[#N]` ou un commentaire de décision ouverte, note-la bloquée (ligne `[orchestrateur] #N bloquée` dans le journal, une fois) ; sinon, si une PR `fix/night-N` est ouverte, note `#N PR à relire (<url>)` dans le journal, sinon `#N à relire`, et ne la relance pas (jamais de relance automatique d'une issue terminée).
5. Parallélisme : compte les threads `running/queued/starting/waiting/preparing` portant `[nuit] #` ou `[fix] #` **dont l'issue n'a pas de PR ouverte**. Tant que ce compte < le maximum de la file et qu'il reste une issue ouverte, sans thread, non bloquée, non « à relire » et dont les prérequis sont livrés (prérequis : chaque `#M` cité dans la ligne de la file ou dans la section « Dépend de » du corps, `gh issue view N --json body` ; livré = `#M` fermée ET `git log origin/main --oneline --grep '#M'` non vide ; sinon ligne `[orchestrateur] #N bloquée (prérequis #M)` une fois, sans lancer) : lance-la avec `t3_thread_launch` : `title` = `[nuit] #N <titre court>`, `workspaceStrategy` = `{type:"worktree", baseRef:"origin/main", startFromOrigin:true, branch:"fix/night-N"}`, `message` = contenu de `/home/sdu/Documents/projects/perso/evetools/.claude/tasks/loop-issue-thread-prompt.md` avec `{N}`, `{TITLE}`, `{CIRCUIT}` remplacés (circuit et titre depuis la file ; lis le fichier avec Read), `clientRequestId` = `night-N-<date>`. Ajoute `[orchestrateur] #N lancée (<link du thread>)` au journal. Un seul lancement par issue. Exception : une ligne de file qui contient « décision AAAA-MM-JJ » est une issue débloquée par Sylvain ; elle se relance une fois si tous ses threads existants ont été créés avant cette date (ses anciennes lignes Blocage ou « bloquée » du journal ne comptent plus), avec `branch:"fix/night-N-d"`, `clientRequestId` = `night-N-d-<date>`, et le message précédé de « Décision de Sylvain : lis le dernier commentaire de l'issue, il fixe le périmètre ; ne rouvre pas le blocage. ».

Source : `zsh -ic 'gh issue list --state open --limit 200 --json number,title,labels'`. Exclues : label `circuit:decision` ou `investigation` ; issue citée dans les lignes « Exclues » ou « Pas dans cette boucle » de la file ; issue notée bloquée, caduque ou en décision dans le journal ; issue qui a déjà eu un thread `[nuit] #N` ou `[fix] #N` (`t3_thread_list` titleContains `#N`) : son reliquat est trié par Sylvain ; Makefile, `.docker/`, CI, déploiement.
