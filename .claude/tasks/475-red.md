## Précision de contrat

`researcherCharacterId` et `CharacterSkillLevels::levelOf($characterId, …)` : les tests unitaires utilisent des entiers quelconques ; le test fonctionnel pose les compétences sur le personnage principal du propriétaire. L'id est donc l'id EVE (`Character::getEveCharacterId()`), pas l'UUID ; l'adaptateur doit résoudre le personnage par cet id.
