# Scopes ESI

Ce tableau est généré depuis le code par `app:help:generate-tables` : ne le modifiez pas à la main.

| Scope | Usage |
| --- | --- |
| `esi-assets.read_assets.v1` | Inventaire de vos personnages (page Inventaire, valeur des assets, matériaux disponibles pour les projets). |
| `esi-assets.read_corporation_assets.v1` | Inventaire de la corporation dans les divisions de hangar que vous avez le droit de voir. |
| `esi-characters.read_corporation_roles.v1` | Lit vos rôles en corporation (Director, Station_Manager…) pour savoir quelles données de corporation vous pouvez lire. |
| `esi-corporations.read_divisions.v1` | Noms des divisions de hangar et de wallet de la corporation. |
| `esi-corporations.read_structures.v1` | Structures de la corporation : jumpgates Ansiblex, raffineries lunaires, santé des structures d'un projet. |
| `esi-wallet.read_character_wallet.v1` | Transactions du wallet d'un personnage, pour rattacher les achats aux projets Industrie. |
| `esi-wallet.read_corporation_wallets.v1` | Journal du wallet de la corporation, pour la taxe lunaire. |
| `esi-contracts.read_character_contracts.v1` | Contrats d'un personnage : ventes et contrats de courrier liés aux projets, données PVE. |
| `esi-industry.read_character_jobs.v1` | Jobs d'industrie d'un personnage (Slot Tracker, suivi des projets). |
| `esi-industry.read_corporation_jobs.v1` | Jobs d'industrie de la corporation, pour les jobs lancés pour son compte. |
| `esi-industry.read_character_mining.v1` | Registre de minage d'un personnage et opérations de minage. |
| `esi-industry.read_corporation_mining.v1` | Extractions lunaires et registre des observateurs de la corporation. |
| `esi-characters.read_blueprints.v1` | Blueprints personnels, pour la bibliothèque de blueprints et le ME/TE des projets. |
| `esi-corporations.read_blueprints.v1` | Blueprints de la corporation, pour la bibliothèque de blueprints. |
| `esi-skills.read_skills.v1` | Compétences d'un personnage : durées d'entraînement, niveau de retraitement. |
| `esi-skills.read_skillqueue.v1` | Demandé à l'avance : aucune fonction ne lit encore la file d'entraînement. |
| `esi-location.read_location.v1` | Demandé à l'avance : aucune fonction ne lit encore la position du personnage. |
| `esi-location.read_ship_type.v1` | Vaisseau actuel d'un personnage, pour les opérations de minage. |
| `esi-location.read_online.v1` | Demandé à l'avance : aucune fonction ne lit encore l'état en ligne du personnage. |
| `esi-fleets.read_fleet.v1` | Demandé à l'avance : aucune fonction ne lit encore la flotte. |
| `esi-universe.read_structures.v1` | Noms et emplacements des structures de joueurs. |
| `esi-search.search_structures.v1` | Recherche de structures, pour retrouver les jumpgates Ansiblex. |
| `esi-characters.read_notifications.v1` | Demandé à l'avance : aucune fonction ne lit encore les notifications du jeu. |
| `esi-killmails.read_killmails.v1` | Demandé à l'avance : aucune fonction ne lit encore les killmails. |
| `esi-markets.structure_markets.v1` | Prix du marché d'une structure, pour comparer avec Jita. |
| `esi-markets.read_character_orders.v1` | Ordres de vente de vos personnages, comparés au meilleur prix du marché. |
| `esi-ui.open_window.v1` | Ouvre une fenêtre du jeu (infos, marché, contrat) depuis l'application. |
| `esi-ui.write_waypoint.v1` | Définit la destination dans le jeu depuis l'application. |
| `esi-corporations.read_projects.v1` | Projets de corporation, pour les contributions PVE. |
| `esi-planets.manage_planets.v1` | Colonies planétaires : extracteurs, alertes d'arrêt. |
| `esi-characters.read_standings.v1` | Standings du personnage, pour les frais de vente et de courtage. |
