  1. Une seule action primaire, biseautée. « Nouveau projet » est le seul bouton plein (coins coupés façon HUD) ; « Configuration » devient un bouton nommé au lieu d'une icône isolée.
  2. 8 onglets en 2 familles. « Suivi » et « Analyse », libellés français homogènes (à valider avec le glossaire).
  3. Filtres explicites avec compteurs ; l'état est gardé dans l'URL comme les onglets (useTabQuery).

  5. Maître-détail et noms longs. Cliquer une ligne remplit le panneau. Dans le tableau, le nom du produit se coupe avec « … » et l'infobulle donne le nom complet ; dans le panneau, il peut tenir sur 2 lignes. Une icône introuvable affiche « ? » au lieu d'un trou.
