## 6. Choix figés au-delà de la spec

2. `MiningFleetStorageSettlement::$debts` est une `list<int>` alignée sur les positions, avec 0 pour le destinataire et pour qui n'a pas de dette.
3. `MiningFleetStorageVerifier::verify(MiningOperation, User $reader)` ; constructeur `(VisibleCorporationAssetsFinder, CachedAssetRepository, CorpAssetVisibilityRepository, OreValueService, MinedQuantityCalculator, TypeNameResolver, CorporationContainerContents = new …)` ; lignes en VO `MiningFleetStorageVerificationLine`.
4. `assetsReadAt` est renseigné dès que les assets visibles ont été lus (R20.8 et suivantes, donc aussi pour `container_not_found` et `delivered_quantity_unknown`), et `null` avant. `containerName` est toujours celui de l'opération, `nothing_delivered` compris.
5. En `unknown`, les lignes attendues restent présentes pour toutes les raisons, sauf `delivered_quantity_unknown` (R23).
6. `canDeclare` est faux sur la ligne du destinataire, pour tout lecteur, et faux partout quand les parts sont figées.
7. VP3 : seuls les champs d'Aria sont figés à `null`. Le sort des dettes des autres participants quand une seule valeur gardée est inconnue n'est pas figé.
8. Constructeurs des providers et processors : celui de `MiningFleetStorageProvider` est `(Security, MiningOperationRepository, MiningOperationAccess, TypeNameResolver, MiningOperationResourceMapper)`. Le provider de déclaration y ajoute `MiningOperationMemberRepository`. Les deux processors prennent `(Security, MiningOperationRepository, MiningOperationMemberRepository, MiningFleetStorageDeclarations, MiningOperationAccess, TypeNameResolver, MiningOperationResourceMapper, MercurePublisherService)`. Le provider de vérification prend `(Security, MiningOperationRepository, MiningOperationAccess, MiningFleetStorageVerifier, MiningOperationResourceMapper)`. 9. Forme d'une déclaration dans la ressource : `{memberId, characterName, delivery, quantities: [{typeId, typeName, quantity}], canDeclare}`. Les quantités valent `[]` hors `partial`. Côté entité, `getFleetStorageQuantities()` rend `array<typeId, quantity>`, ou `null` hors `partial`.

11. Front : le sélecteur de chaque participant est un `role="group"` dont l'`aria-label` est son nom, avec des boutons `aria-pressed`.
