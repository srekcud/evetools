2. **Recalcul en échec** : `computedAt` est mis à jour aussi quand la lecture échoue (test `testAnEsiErrorMakesThePreviouslyKnownYieldUnknown`) ; le rendement connu précédent est effacé (Y3 : jamais de valeur par défaut).
3. **Cascade** (suppression de l'utilisateur ou du personnage) : portée par le mapping et la migration de phase verte ; pas de test d'intégration (refusé après migration).
4. Validation dans le processor (400 par `BadRequestHttpException`), pas par contraintes Validator (qui rendraient 422) : la spec demande 400.
5. `findOneBy(['user' => $user])` est le contrat de lecture du profil dans le harnais.
6. Y11 non testé : `MiningTab` et ses entrées gardent leur `localStorage`, couverts par les tests existants.
