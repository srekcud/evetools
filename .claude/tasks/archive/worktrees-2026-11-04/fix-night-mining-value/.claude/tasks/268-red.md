1. **Conflit rendement 0** : la spec (cas limites) veut un retraité 0 connu ; `OreValueService` ne rend un `reprocessValue` que s'il est `> 0`, et `OreValueServiceCharacterizationTest::testLeavesTheReprocessValuesUnknownWhenMineralsAreWorthNothing` fige `null` pour des minéraux à 0. Le test « yield 0 » est écrit ; le cas « minéraux à 0 » ne l'est pas dans la table (V3 lit la source telle quelle). L'implémentation doit rendre 0 connu pour un rendement 0 sans casser ce test existant, ou Sylvain tranche.
2. **T3 et le Compressed Fullerite-C50** : le harnais a un « Compressed Fullerite-C50 » à 2 813 ; la spec attend un compressé `null` pour le gaz. Les tests de la table utilisent les seuls prix de la spec (sans prix pour le gaz compressé ni pour les produits de glace, sinon T2/T9 changent). Si la table doit ignorer le compressé du gaz même avec un prix, c'est à ajouter à la spec.
3. T11 (non publié / sans groupe de marché / hors catégorie) est porté par le test d'intégration du dépôt ; le service ne filtre que les noms.
